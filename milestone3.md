## Group discussion:
 Strengths and weaknesses of Dungeon Runner.
		Kylen: I believe Dungeon Runner’s biggest strength is it’s game loop, the search, fight and loot -> return -> buy -> search again is a lot of fun. However there are a few bugs with animations, such as the player still playing the falling animation a few seconds after they’ve landed.

 Process and communication during development
		Kylen: We had weekly meetings throughout the project to organise ourselves, we also communicated on our discord server fairly frequently to let each other know what we finished working on.

 Version control
		Kylen: We created issues for each feature/bug/refactor to be created/resolved, describing what was to be done in the issue description before creating a branch for that issue and committing to it using consistent and conventional commit messages.

 Best parts of project
		Kylen: For me the best part of the project was working on the more visual parts of the player. Completing those parts were very satisfying to see, such getting the animations to work correctly, getting the player’s boomerang to bounce off of walls and getting the player’s weapons to appear in just the right spot in their hands.
